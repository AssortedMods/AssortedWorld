# Assorted Portals

Adds void crystal, found in the outer End islands and in end city chests. With it you can craft void portal frames and a void striker to build an end portal anywhere you like, on a floor, a wall or a ceiling.

Also included in [Assorted World](../world). Worlds made with Assorted World 9.x keep everything when you switch to this mod.

Requires [Assorted Lib](https://github.com/AssortedMods/AssortedLib).
