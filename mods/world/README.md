# Assorted World

Adds a variety of structures and world generation features. This includes Assorted Structures, Assorted Portals,
Assorted Plants, Assorted Floating Islands and Assorted Terrain in one download.

If you only want some of them you can install those mods on their own instead. Your world keeps everything either way.

Requires [Assorted Lib](https://github.com/AssortedMods/AssortedLib).
